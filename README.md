# AR MMD

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

AR space MMD model and animation playback demo application.

## Demo
https://code4fukui.github.io/ar-mmd/

## Features
- Load MMD models
- Play MMD animations
- Place in AR space

## Requirements
- WebGL-enabled browser

## Usage
Clone the repository and open index.html to see the demo.

## Data
- Model: [Nakano Sisters MMD Model](https://twitter.com/nakasis_)
  - License: No report required, secondary creation, modification, and commercial use allowed.
- Motion: [Throwing ZIP (Pitching Motion) - BowlRoll](https://bowlroll.net/file/22865)
