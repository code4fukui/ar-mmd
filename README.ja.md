# AR MMD

AR空間でのMMDモデルおよびアニメーション再生のデモアプリケーション。

## デモ
https://code4fukui.github.io/ar-mmd/

## 機能
- MMDモデルの読み込み
- MMDアニメーションの再生
- AR空間への配置

## 動作環境
- WebGL対応ブラウザ

## 使い方
リポジトリをクローンし、index.htmlを開いてデモを確認してください。

## データ
- モデル: [中野シスターズMMDモデル](https://twitter.com/nakasis_)
  - ライセンス: 報告不要、二次創作、改変、商用利用可。
- モーション: [投げるZIP(投球モーション) - BowlRoll](https://bowlroll.net/file/22865)
  - ライセンス: 動画や画像での使用、改変、再配布に制限なし。
